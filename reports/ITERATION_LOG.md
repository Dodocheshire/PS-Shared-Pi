# PS-CBM 迭代记录

## 基线

官方文件名划分与类别映射已通过 CIFAR-10、CIFAR-100、CUB 全数据清单核验，教师为 CLIP ViT-B/16，目标为 RN50 2048 维倒数第二层浮点特征。全部训练与验证特征准备不编码测试特征。最佳 CBL 保存问题单独记录并分别拟合官方末轮与克隆保存的最佳验证状态；两个头的训练独立重设相同种子以配对。

- CIFAR-10：61 概念，完整验证准确率 90.74% / 90.72%（官方末轮 / 最佳验证）。
- CIFAR-100：583 概念，完整验证准确率 72.16% / 72.36%。
- CUB：509 概念，官方末轮验证准确率 68.65%；最佳验证状态的 SAGA 仍在运行，最终以状态文件和输出指标为准。

以上均为基线种子 42，不是五种子或测试集成绩。

## 第一轮：条件均值与共享因子噪声

CBL 与分类头冻结，生成器仅接收标准化的预测概念。所有学习方法分配 24,964 个参数（CIFAR-10）。共享因子覆盖 14/61 个概念，类别集合仅来自训练构建的概念库。独立抽样与共享因子抽样的协方差是对角非负矩阵与因子外积之和，始终半正定；无共享关系的两行共享因子内积为零。训练批次和初始化匹配。MC 使用反向配对采样减少方差。

先登记两个概念/能量权重组合，每组四种学习方法，并加固定高斯对照，共九组；40 epoch，适配种子 0。最高验证准确率 90.94%，同容量适配、对角 Pi、共享 Pi 均达到；Pi 关闭尺度后成绩相同。随机能量比例约 0.2%，NLL/ECE 高于基线。结论：没有独立随机性收益，不能推进该配置为最终方案。

原始第一轮确定性控制将多个线性输出相加，分配参数数匹配，但数学上可合并为一个线性均值头。它支持本轮“未证明噪声增益”的结论；第二轮改成独立非线性分支，作为更强的容量控制。

## 第二轮：mixup 与校准门槛

在预测概念空间混合训练样本、分类目标和概念伪标签。固定两种 mixup 强度（0.2 / 0.4）、四种方法、60 epoch，增加尺度可学习范围。先满足预设的 NLL、ECE、概念 BCE 与能量限制，再按验证准确率与 NLL选模。未达到门槛的模型不能晋级，即使单独准确率更高。第一组仅均值实验保留了未修改的基线，尚无满足门槛的提升。后续案例仍由实际进程串行完成。

## 第三轮：使概念目标与预测概率一致

对 CIFAR-10 验证概念的独立固定高斯诊断（尺度 0.1），干净 BCE 为 0.06815，期望每次采样 BCE 约 0.07394，但平均概念概率对应 BCE 约 0.06767。后者对应实际预测概率，前者含凸性带来的采样惩罚。

第三轮因此分别采用分类 MC 边际似然和概念 Bernoulli MC 边际似然，同时输出预测 BCE 与期望 BCE，保留对照、相同参数、校准和语义门槛。此处不是修改旧指标定义来宣告成功：前两轮输出不变，第三轮在独立目录记录新目标的实际训练与验证成绩。已登记不使用 mixup / 强度 0.2 的八组对照，结果尚待完成。

## 后续证据

仍需在三个数据集持续验证新的结构/目标/策略，锁定方案后独立五种子测试、配对区间、CUB 人工属性与解释/校准检查。测试集保持隔离，不用当前探索成绩代替最终证据。若尺度收益仍不成立，将依据记录继续调整，不能把均值适配增益改名为噪声收益。
